# ainops-platform
AINOPS - AI-assisted, read-only network troubleshooting platform.

Today: React + FastAPI, a LangChain/LangGraph agent over MCP tools, and a Neo4j knowledge graph.
Target for production: PostgreSQL (with pgvector) as the system of record next to Neo4j, see
[docs/architecture-production.md](docs/architecture-production.md).
